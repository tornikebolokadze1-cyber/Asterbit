# Memory — მეხსიერების ფენები

## სტრუქტურა

- `now.md` — ახლანდელი მდგომარეობა (≤120 ხაზი). ყოველი სესიის დასაწყისში იკითხება.
- `episodic/handoffs/` — თითო სესიაზე ერთი მოძრავი handoff (შეკუმშვის შეჯამება).
- `episodic/sessions/` — სესიების შეჯამებები (`/sdlc-wrap`).
- `semantic/` — მყარი ფაქტები თემების მიხედვით და თვის დაიჯესტები.
- `archive/` — ძველი ვერსიები. არასდროს იშლება და ავტომატურად არ იტვირთება.

## წესები

1. ეს ფაილები ჭეშმარიტების წყაროა; ნებისმიერი ძიების ან გრაფის ინდექსი მათგან აიგება.
2. აქ არასდროს იწერება საიდუმლოებები, სხვისი პერსონალური მონაცემები და ვებიდან ან უცხო ფაილიდან სიტყვასიტყვით აღებული ტექსტი.
3. ყოველი ცვლილება git-ში ჩანს: `git log -p memory/` გაჩვენებს, რა როდის შეიცვალა.
