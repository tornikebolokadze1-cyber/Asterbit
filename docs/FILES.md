# FILES — ყველა ფაილი: რისთვისაა და რას აკეთებს

> **ვისთვის:** მფლობელისა და თანამშრომლებისთვის — ვისაც პროექტის აგებულების გაგება სჭირდება.
> **წესი:** ფაილის დამატების, გადატანის ან სახელის შეცვლისას ეს რუკა იმავე ცვლილებაში ახლდება. ყველა ბმული რეპოს ფაილზე მიუთითებს.

რეპოში ფაილები ოთხ ჯგუფად იყოფა. პირველი ადამიანებისთვისაა: სახელმძღვანელო, შეთანხმება, თანამშრომლის გზამკვლევი და დღიური. მეორე Claude-ისთვისაა: წესები, ეტაპების ბრძანებები და დამხმარე აგენტები. მესამე პროექტის ოფიციალური ჩანაწერებია: სად ვართ, რა გადავწყვიტეთ, რა დარჩა და რა გვახსოვს. მეოთხე ძრავის ბიბლიოთეკაა: ცარიელი ფორმები (თარგები), დიზაინები და კვლევა. თითქმის ყველა ფაილი markdown-ია (ჩვეულებრივი ტექსტი სათაურებით, სიებითა და ცხრილებით), ამიტომ VS Code-შიც, Obsidian-შიც და GitHub-ზეც ერთნაირად იკითხება.

## `.claude/agents/` — ოთხი დამხმარე აგენტი

Subagent (დამხმარე აგენტი) ცალკე Claude-ია საკუთარი კონტექსტით: მთავარი საუბრის მსჯელობას ვერ ხედავს, საკუთარი მოდელი და შეზღუდული ხელსაწყოები აქვს და მთავარ სესიას მხოლოდ შედეგს უბრუნებს. ასე შემმოწმებელი ავტორისგან დამოუკიდებელია, მთავარი კონტექსტი კი სუფთა რჩება.

- [`architect.md`](../.claude/agents/architect.md) — Opus 5.5, მაღალი effort; მხოლოდ კითხვა და ვებში ძიება. ერთ გადაწყვეტილებაზე 2–3 ნამდვილ ვარიანტს იძლევა წყაროებით, პლუსებით, მინუსებით, ფასით, რისკით და შექცევადობით, ბოლოს — რეკომენდაციას. გადაუმოწმებელს „UNVERIFIED"-ით ნიშნავს.
- [`auditor.md`](../.claude/agents/auditor.md) — Opus 5.5, მაღალი effort. ყოველ კარიბჭეზე, ყოველი ეტაპის კოდზე და ყოველ `[high-risk]` დავალებაზე ამოწმებს სისრულეს, ზედა დოკუმენტებთან თანხვედრას და მტკიცებულებებს. ხელახალ შემოწმებაზე მხოლოდ გასწორებას უყურებს (გასწორდა / არ გასწორდა). პირველი ხაზი: `VERDICT: PASS / PASS-WITH-FINDINGS / FAIL / INCONCLUSIVE`, მეორე — `COUNTS: high=… medium=… low=…` ჟურნალისთვის. არასდროს ასწორებს და არასდროს ამტკიცებს.
- [`verifier.md`](../.claude/agents/verifier.md) — Sonnet 5.5, საშუალო effort. სუფთა კონტექსტში უშვებს გეგმის შემოწმების ბრძანებებს და თითოეულზე წერს MATCH / MISMATCH / COULD-NOT-RUN; „VERIFIED" მხოლოდ მაშინ, როცა ყველაფერი დაემთხვა.
- [`scout.md`](../.claude/agents/scout.md) — Haiku 5.5, საშუალო effort, მხოლოდ კითხვა და ვებში ძიება, ბრძანებების გაშვების გარეშე ([ADR-0007](decisions/0007-claude-only-orchestration.md), ვარიანტი A). სწრაფად პოულობს ფაქტებს: ბიბლიოთეკის ვერსიას, ფასს, დოკუმენტაციის გვერდს, სად წერია რამე რეპოში, გრძელი გვერდის შეჯამებას. ყოველ ფაქტს წყაროს და შემოწმების თარიღს უწერს. არ წყვეტს და არ ასწორებს; მის პასუხს გადაწყვეტილებამდე უფრო ძლიერი მოდელი ამოწმებს. Claude Code ≥ 2.1.293 სჭირდება.
